# CipherVault

CipherVault is a Python-based password security toolkit that helps users check password strength.

## Features

* Password Strength Checker
* Regex-based Password Validation
* Weak and Strong Password Detection
* Command Line Interface (CLI)

## Technologies Used

* Python
* Regular Expressions (Regex)

## Project Structure

CipherVault/
├── main.py
├── passwords.json
├── requirements.txt
└── utils/
├── password_strength.py
├── password_generator.py
└── encryption.py

## How to Run

1. Open Terminal
2. Navigate to the project folder
3. Run:

python main.py
